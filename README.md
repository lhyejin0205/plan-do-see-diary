# 플랜두씨 다이어리 2 (T07) — 로그인과 내 기록 잠그기

> 이 브랜치(`t07`)는 T06 다이어리에 회원가입·로그인을 붙인 버전입니다. T06 공개 다이어리(`main` 브랜치, `pds_*` 표)는 그대로 둡니다.

- 첫 화면은 로그인·회원가입 화면입니다. 기록은 로그인한 뒤에만 보입니다.
- 모든 기록은 `pds7_*` 표에 저장되고, 서버의 행 수준 보안(RLS)이 **로그인한 본인 행만** 허용합니다. 로그인하지 않은 요청과 다른 계정의 요청은 서버가 거절합니다.
- "관찰 규칙" 카드에 5일 관찰의 질문·지표·단위·계산 규칙을 저장합니다. 규칙을 바꾸면 새 버전으로 남아 바꾸기 전후를 비교할 수 있습니다.

## T07 설치

1. Supabase SQL Editor에서 `supabase/schema-t07.sql`을 실행합니다. (T06 표는 건드리지 않습니다.)
2. Supabase → Authentication → URL Configuration에서 **Site URL**과 **Redirect URLs**에 T07 배포 주소를 넣습니다. 확인 메일의 링크가 이 주소로 돌아옵니다.
3. Authentication → Providers → Email이 켜져 있는지 확인합니다. "Confirm email"을 켜 두면 가입 뒤 메일 확인이 필요합니다.
4. 이 브랜치를 T06과 다른 Vercel 프로젝트(또는 다른 주소)로 배포합니다. T06 주소는 계속 공개 다이어리로 남아야 하기 때문입니다.

# 플랜두씨 다이어리 1 (T06)

내가 실제로 세운 계획(Plan) → 실제로 한 일(Do) → 돌아보기(See)를 서버 데이터베이스(Supabase)에 저장하는 웹앱입니다.

- 날짜를 골라 그날의 계획을 적고, 계획마다 실제로 한 양과 한 일을 기록합니다.
- 목표 수치를 적으면 실제/목표 달성률이 표시됩니다.
- 하루 끝에 잘된 점 · 아쉬운 점과 이유 · 다음에 바꿀 한 가지를 남깁니다.
- 오른쪽 위 버튼으로 내 자료 전체를 JSON 파일 하나로 내보냅니다.
- 모든 자료는 Supabase에 저장되므로 새로고침하거나 브라우저를 닫았다 열어도 남습니다.

> **로그인이 없습니다.** 링크를 아는 사람은 누구나 보고 고칠 수 있습니다. 남이 봐도 괜찮은 계획과 기록만 적습니다. 로그인과 "내 자료는 나만 보기"는 T07에서 붙입니다.

## 설치와 배포

1. **Supabase**
   1. https://supabase.com 에서 새 프로젝트를 만듭니다.
   2. 왼쪽 **SQL Editor** → New query 에 `supabase/schema.sql` 내용을 전부 붙여 넣고 **Run** 합니다.
   3. **Table Editor**에 `pds_plans`, `pds_dos`, `pds_sees` 세 표가 생겼는지 봅니다.
   4. **Project Settings → API**(또는 API Keys)에서 Project URL과 anon public(또는 publishable) 키를 복사합니다.
2. **config.js** 의 `YOUR_SUPABASE_URL`, `YOUR_SUPABASE_ANON_KEY` 를 복사한 값으로 바꿉니다.
   - service_role / secret 키는 절대 넣지 않습니다.
3. **GitHub** 에 공개 저장소를 만들고 이 폴더 전체를 올립니다.
4. **Vercel** → Add New → Project → 그 저장소 → Deploy. 1~2분 뒤 `https://무언가.vercel.app` 주소가 나옵니다.

## 날짜 규칙 (요약)

- 모든 날짜는 한국 시간(Asia/Seoul) 달력 날짜 `YYYY-MM-DD` 입니다. 기기 시간대가 달라도 '오늘'은 한국 날짜입니다.
- 실제로 한 날짜(Do)는 계획한 날(Plan)보다 앞설 수 없습니다. DB 트리거가 막습니다.
- 돌아보기(See)는 하루에 하나입니다. 다시 저장하면 그날 것을 고칩니다.

자세한 내용은 `contracts/pds-schema-v2.json` 을 봅니다.
