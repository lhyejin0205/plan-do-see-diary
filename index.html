플랜두씨 다이어리

계획(Plan) → 실제로 한 일(Do) → 돌아보기(See)

공개 다이어리입니다. 로그인이 없어서 이 링크를 아는 사람은 누구나 보고 고칠 수 있습니다. 남이 봐도 괜찮은 계획과 기록만 적고, 다른 사람의 이름·연락처나 민감한 내용은 적지 않습니다.

Supabase 연결이 필요합니다

config.js에 Supabase Project URL과 공개용 키가 아직 들어 있지 않습니다.

  1. Supabase에서 프로젝트를 만들고, SQL Editor에서 supabase/schema.sql을 실행합니다.
  2. Project Settings → API에서 Project URL과 anon(또는 publishable) 키를 복사합니다.
  3. config.js의 두 값을 바꾸고 다시 배포합니다.
